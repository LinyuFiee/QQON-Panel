# 公网 IP HTTPS（v0.6 开发中）

::: info v0.6 开发中
以下为待发实现，以 Release 及其安装器帮助为准。当前公开 `latest` 仍为 **v0.5.0**，默认回环安装不变；本页不是 v0.5 的公网安装步骤。
:::

## 新安装的默认流程

v0.6 新安装拟默认采用 **`public-selfsigned`**：公网 IPv4、自签 HTTPS，默认端口 **`8443`**。中文交互中须由用户核对并确认服务器的公网 IPv4，再写入配置；不能把内网地址、代理出口或他人的 IP 当作自己的入站地址。

访问地址形式为 `https://<已确认的公网IPv4>:8443/`，选择其他端口时以实际配置为准。该链接只表示配置结果，不保证外网能连接。旧版安装不会自动切换此默认值，见 [旧版迁移顺序](./maintenance#从-v0-4-v0-5-迁移)。

## 自签证书与浏览器提示

自签证书不受浏览器默认信任，访问时出现证书警告是预期现象，不代表已经获得公共 CA 认证。

- 从可信的服务器终端取得安装器或维护入口显示的证书指纹（SHA-256 fingerprint）。
- 在浏览器查看服务器证书，核对地址和指纹；只在确认来源与指纹一致后决定是否继续。
- 指纹不一致、地址不符或无法确认服务器身份时停止访问，不输入账号或初始化令牌。

不要为消除提示关闭浏览器或系统的全局证书检查。自签 HTTPS 提供加密，但不能替代身份核验和访问控制；证书私钥应保持私有。

## 还需要检查网络

安装器生成证书和访问配置，不等于以下条件自动满足：

| 条件 | 管理员需确认 |
| --- | --- |
| 公网 IPv4 | 地址确实属于本机或可转发到本机的入口，允许入站连接 |
| 云安全组 | 实际 HTTPS 端口的 TCP 入站规则及允许来源 |
| NAT / 路由 | 如有地址转换，公网端口正确转发到面板所在主机 |
| 主机防火墙 | 对应端口、接口和来源已按实际需要配置 |

`qqon status` 和 `qqon url` 只读查看本机状态及配置，不自动修复网络，也不证明外网可达。应从管理员控制的外部网络单独验证，不把本机访问成功当作外网验证通过；尽量限制允许访问的来源。

## 改配置与换证

- `qqon config` 用于显式调整访问配置；公网 IPv4 变化后须重新核对地址和对应证书。
- `qqon tls renew` 用于自签证书更新；换证后指纹可能变化，需要重新核对。
- 配置与证书切换使用事务，保留旧状态并检查结果；失败时保留记录，不跳过校验或删数据重装。

这些操作需 Linux root 或 Windows 管理员权限，服务仍使用固定的受限账号。它们不自动开通云安全组、NAT 或防火墙，不提供外网可达保证，也不等同自动申请受公共 CA 信任的证书。

旧版 v0.4/v0.5 必须先显式迁移管理器、保留旧访问，再升级新程序，最后选择是否配置公网 HTTPS。完整说明见 [qqon 维护](./maintenance)；当前正式安装仍按 [v0.5 快速开始](./quickstart)。
