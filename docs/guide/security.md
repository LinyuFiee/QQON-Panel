# 安全边界

## 管道安装与来源

首页的一行命令会立即执行远程内容，不等同于“先审阅再运行”。它依赖 GitHub Pages、`LinyuFiee/QQON-Panel` 仓库、Release 发布权限和 HTTPS；对这些来源有疑问时，不要执行。

文档构建只复制仓库 bootstrap，入口再选择正式 Release。安装器核对清单、大小、SHA-256、归档内容和程序身份，但**清单与产物属于同一发布源，哈希不是独立签名**。不要使用不明镜像、关闭证书检查、执行下载目录里的辅助文件或让远程参数决定任意脚本路径。

更审慎的流程见 [先下载审阅](./installation#下载与信任)。v0.5.0 已发布；新入口仍必须拒绝不兼容的 v0.4.0 六附件格式，旧版升级通过 [显式管理器迁移](./upgrade-migration#manager-migration) 处理，不绕过安全检查。

## 监听与反向代理

- 官方安装路径默认 `127.0.0.1:5173`；v0.5.0 首次安装可选端口，仍固定回环监听。
- 本地访问或 SSH 隧道不需要开放公网面板端口。
- 远程 Web 访问应使用**独立 HTTPS Origin**与已有反向代理；不要与用户上传、用户站点等不可信内容共用来源。
- 域名、证书、DNS、代理与防火墙不是安装器自动配置范围。不要为解决 Host/Origin 不匹配而关闭校验或公开 HTTP。
- 不信任任意代理头；在改变代理或 Origin 前先评估实际请求的 Host、协议和 Cookie 行为。

## 账号、令牌与私有数据

首次初始化没有默认密码。初始化令牌、账号文件、TOTP 种子与恢复码应只在受保护的本机路径或加密备份中保存；不要提交到 Git、复制到工单或放进公开截图。

密码使用派生后存储，登录有请求限流，会话 Cookie 具有安全约束；这些机制不能代替强密码、主机补丁与访问控制。密码/TOTP 变更和重启会使相关会话失效，需要重新登录。

备份前停止面板以获得一致的私有数据副本；备份本身也包含敏感内容。恢复时先在隔离测试路径核对权限与版本，不能把“二进制回退”误解为“所有数据都可自动回退”。

## 最小权限

### Linux

安装与升级由 root 显式执行；面板服务使用低权限 `server-panel` 账号。程序、管理器、systemd unit、安装记录不应由面板账号修改。检测到未知安装、符号链接或不安全权限时应停止，不用批量 `chmod 777` 或改成 root 运行来解决。

文件浏览需显式授权根目录，不能覆盖面板私有数据。Docker Unix socket 即便用于只读网页功能，也可能赋予进程接近 root 的主机能力；默认不开写操作，授权前应单独评估，优先考虑隔离与 rootless Docker。

### Windows {#windows-v0-5-待发布}

使用原生 SCM 服务与虚拟账号 `NT SERVICE\QQONPanel`。Program Files 程序目录只允许管理员/SYSTEM 修改，服务账号读取执行；ProgramData 私有数据仅允许管理员、SYSTEM 与服务身份访问。

受保护 ACL、所有者与重解析点检查失败时不静默放宽权限。已有开发目录不一定满足服务安装要求，不应让安装器自动接管不明目录。不要关闭 UAC、防病毒、执行策略或给 `Everyone` 完全控制；详见 [Windows 服务](./windows-services)。

## 更新与归档

校验发生在切换程序前。受限解包只接受预期的普通程序文件，拒绝路径穿越、链接、额外文件及超限内容。下载/校验错误不能通过手工拼装 `release.json` 或 `SHA256SUMS` 修补。

升级保留事务记录并尝试回退二进制，但磁盘损坏、断电和权限变化仍可能阻止恢复。普通升级拒绝降级和不兼容数据格式；不要删除锁文件、事务或旧程序备份来强行继续。

## 本文档的网络与数据

本站使用 VitePress 本地全文搜索，搜索索引随静态站点加载；没有配置外部搜索 API、分析脚本、遥测或 CDN 字体。主题与资源由本站提供。点击 GitHub 链接、下载安装器/Release 或面板内手动检查更新会访问相应外部服务；这些操作不等同于本站搜索。
